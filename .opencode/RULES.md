# Global Rules

## General

- Never use any in TypeScript.
- Use strict typing.
- Code must be written in English.
- Avoid unnecessary comments.
- Prefer composition over inheritance.
- Follow SOLID principles.
- Follow clean architecture
- Explain major decisions.

## Backend

- Use NestJS.
- Use DTOs for requests and responses.
- Validate all inputs.
- Use dependency injection.
- Separate controllers, services and repositories.
- Handle errors explicitly.

## Frontend

- Use React with hooks.
- Components should be small.
- Avoid duplicated logic.
- Extract reusable hooks.

## Database

- Never remove columns without confirmation.
- Prefer soft delete.

## Tests

- Unit tests required.
- Integration tests for APIs.
- Never finish until tests pass.

## Safety

- Ask before deleting files.
- Ask before changing infrastructure.
- Ask before modifying secrets.
